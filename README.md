# Gestor de Medicacion y Recordatorios

Aplicacion movil y API REST para el seguimiento personal de recetas medicas, retiros en farmacia y recordatorios de renovacion.

## Tecnologias principales

- **Backend:** Python, FastAPI, PostgreSQL
- **Mobile:** Flutter
- **Autenticacion y avisos:** Inicio de sesion mediante codigo temporal y notificaciones programadas

## Estructura del repositorio

- `backend/`: API REST, logica de validacion de fechas y motor de alertas.
- `mobile/`: Aplicacion movil multiplataforma con diseno accesible.
